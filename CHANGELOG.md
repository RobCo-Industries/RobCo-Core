# Changelog

## Unreleased

- `tools/sfx_table.py` renders a sound effect model into 8-bit tables: C with each length, CRC-32 and the model's SHA-256, raw `.u8` files or WAV files. `--check` tells when a table is out of date. Every C name and file name it writes holds `sfx`, so none can be a name of C or the system. A run checks its whole plan before it writes: it refuses two files at one path, or one path as a file and a folder, by any spelling, link or case. It resolves each path once and writes only there. A missing field hides no other fault in the model. Output file names are lower case with one `.`, so each header gets its own include guard. It publishes all files as one and restores the old ones on a failure. The format and the synthesis are in `docs/spec/SFX_MODEL.md`.
- `tools/sfx_check.py MODEL DIR` checks that dumped `.u8` tables sound like their model. It compares the band power and the frame level of each table with a prediction from the model, within a tolerance for each kind of sound. The prediction includes the rounding of each sample to a whole step, so a quiet table passes too. Bands and frames have their own gain. The noise prediction covers the smearing of a short envelope and the comb of repeated hits. A sound with noise gets its band width and frame length from its effective duration and bandwidth, and is judged without its bands or frames when fewer than 3 fit. An invalid model exits with code 2. A sound with noise also gets a level check of its peak against the strongest expected rms, and a table that misses the model's power under 15 kHz fails.
- `robco-ci.yml` marks the checkout and every submodule folder, at any depth, as safe for git in both jobs, then checks that git works in each. Before, git refused the checkout in the container with "dubious ownership".
- The harness plugin removes a passing test's `tmp_path` when the test ends. A test that fails or errors in setup, call or teardown keeps its folder. Set `ROBCO_KEEP_TMP=1` to keep every folder. A project that sets `tmp_path_retention_policy` itself keeps its own value.
- `rimg_seal()` and `rimg_pack()` in `src/lib/rimg_seal.c`: the sealer and the packer in C. A host test runs every vector of `tests/vectors/rimg/vectors.ini` through them.
- `tools/rimg.py` reads a PBM icon width or height as 1 to 9 ASCII digits, as the spec asks. It now refuses `+32`, `-32`, `3_2`, `0000000032` and a token with a vertical tab or a form feed with `io`, as the C sealer does. Seven new vectors check it.
- `.gitattributes` turns off end-of-line conversion for test vectors, golden images and byte-compared fixtures, so a Windows checkout with `core.autocrlf=true` keeps their bytes. `tests/tools/test_vector_eol.py` checks it for `tests/vectors/`.
